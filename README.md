# Arabic Eye — الشاهد 👁️

شاهد أي تطبيق (تيرمنال، VS Code، متصفح) من قائمة منسدلة — ضبط تلقائي
كامل: يتابع النافذة، يهدأ مع الثبات، يقرأ مع الحركة، ويروي ما يراه
باحترافية في عمود الدردشة. الحروف: indra-ocr (موديل 76MB يقرأ العربية، 0.2 ثانية) — بديله Tesseract.
السرد العميق: النموذج المحلي Qwen3-VL-8B.

## التشغيل — Arabic Eye Tool
دبل كليك على `run.bat` (المشغل الوحيد) — يفرض UTF-8 ويفتح واجهة الشات
مباشرة بأسلوب Gemini: شريط علوي (Alt + Space) بالحالة،
بطاقات You/Arabic Eye بتشكيل Markdown، حبة السياق بعد اللقطة،
وشريط `Ask anything...`. (واجهة الإطار المتحرك القديمة اتشالت.)

سكريبت محلي بالكامل (Windows 11): لقطة شاشة بـ `mss` (أو Pillow تلقائيا)
تتحفظ باسم `sandra_capture.png`، قراءة بـ indra-ocr (بديله Tesseract)،
إصلاح الترتيب بـ `fixer`، ثم طباعة مشكّلة بـ `arabic-reshaper` و`python-bidi`.

أو من التيرمنال: `python app/terminal_reader.py`
قايمة `App` فيها البرامج المفتوحة (تيرمنال، VS Code، متصفح...) — اختار
ودوس `Read screen`. لو القايمة فاضية دوس `Refresh`، أو `Read fg in 3s`
(دوس الزرار وافتح البرنامج اللي عايزه خلال 3 ثواني).
Enter أو `s` يقرأ الشاشة (مع مؤشر Thinking)، `clear` يمسح،
`logical` يبدل التشكيل، `q` خروج.
`--once` لقطة واحدة، `--region X Y W H` لمنطقة، `--logical` بدون تشكيل
لو تيرمنالك حديث (Windows Terminal بيشكّل العربي لوحده).

## ملاحظات صادقة
- دقة OCR تعتمد على وضوح الخط وحجمه — كبر خط التيرمنال لأفضل نتيجة.
- الأرقام والكود الإنجليزي لا يتأثران — الإصلاح يقلب مقاطع الحروف العربية فقط.
- الحزم: `indra-ocr` و`mss` و`rich` حسب `requirements.txt` — والبدائل
  (Tesseract وPillow) تشتغل تلقائيا لو اتشالوا.

## عقل النملة الذكية — Qwen2.5-0.5B
أي كلام تكتبه في شريط الإدخال (غير `s` و`q`) يروح للمخ مع آخر نص شاشة:
يشرح الأخطاء والأكواد بالعربية ويكتب المطالبات. المخ شغال داخل
الأداة (0.5B، أصغر نملة بتفهم عربي)، ولو وقع فيه بديل LM Studio
(`lfm3-1.7b`). أولاما محظور هنا ولا يستخدم أبدا.

## الملفات
- `app/terminal_reader.py` — واجهة الشات (Rich) + المخ
- `app/ocr_engine.py` — تصوير + OCR
- `app/fixer.py` — إصلاح ترتيب العربي
- `run.bat` — المشغل الوحيد
